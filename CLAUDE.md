# PawConnect

The full AI development guide for this project lives at **`docs/CLAUDE.md`** — read it before any task. It covers the project overview, tech stack, architecture, and coding conventions, and points at `docs/PRODUCT_SPEC.md` and the Supabase migrations for data structure.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (`kydogg/PawConnect`) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels are used as-is: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
