## USAGE TIPS FOR MIDJOURNEY

### Parameter Recommendations:
- **--ar** (aspect ratio): Use 1:1 for icons, 16:9 for headers, 9:16 for full-screen backgrounds
- **--style raw**: Produces cleaner, more controlled results for UI elements
- **--v 6**: Latest version for best quality
- **--q 2**: Higher quality for final production assets

### Prompt Modifiers to Add:
- Add `vector style` for infinitely scalable assets
- Add `high contrast` for better visibility at small sizes
- Add `simple clean design` for UI clarity
- Add `white background` or `transparent background` as needed

### Consistency Tips:
1. Always include the hex color codes in prompts (#EA580C, etc.)
2. Reference "warm sunset orange" consistently across prompts
3. Use "modern flat design" for stylistic unity
4. Mention "friendly and approachable" for brand personality
